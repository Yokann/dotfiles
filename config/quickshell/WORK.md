# Roadmap

Custom Quickshell bar for Hyprland. Each step ships one reviewable, self-contained unit.

- [x] **0 — Scoping.** Constraints and decisions, see `AGENT.md`.
- [x] **1 — Scaffolding.** Directory layout, `Settings`/`Colors`/`Metrics` singletons, widget `Registry`, `Bar.qml`, one placeholder widget end-to-end.
- [x] **2 — Clock.** Bar clock + monthly calendar popup. Settings schema went through several reworks (see `AGENT.md`): per-widget `enabled`/`screens`/`order` → a `display.<barId>.<screen|default>.<section>` placement map → an instance-id/widget-type split (same widget declared multiple times with different config, e.g. `clock_time`/`clock_date`) → `display` folded into `bar.layout` → `bar` became `bars`, a list, so multiple independent bars can be declared (`Bar.qml` now takes a `barConfig`, one per `shell.qml` instantiates via `Variants { model: Settings.bars }`). Also added a `showCalendar` toggle (renders as plain text, not a button, when off) and a generic per-widget `style` (background/hover/radius/animation) resolved by `Pill`. `Pill`/`Popup` moved out of `widgets/common/` into a new top-level `ui/` (reusable UI chrome, not widgets — see `AGENT.md`).
- [x] **3 — Workspaces.** Hyprland workspaces widget (`Quickshell.Hyprland`), dynamic and scoped per-screen. First widget needing `screen`, not just `instanceId` — the widget contract and `Pill` both extended for it (see `AGENT.md`). Each workspace is its own clickable cell (not just the digit's text bounding box), with a distinct filled effect for the globally focused workspace vs. merely-active-on-its-monitor.
- [x] **4 — Tray.** System tray widget (`Quickshell.Services.SystemTray`), global (not per-screen). Left/middle/right click → activate/secondaryActivate/native context menu. Right-click menu needed `//@ pragma UseQApplication` in `shell.qml` (instance pragma, requires a full restart) plus a third injected widget-contract property, `panelWindow`, since `Item.Window.window` isn't an accepted parent for the platform menu — see `AGENT.md`.
- [x] **5 — Audio.** Pipewire service (`services/Audio.qml`: sink/source volume, mute, device lists via `PwObjectTracker`) + bar indicator (`AudioIndicator.qml`) + popup with sliders and device pickers (`AudioPopup.qml`). No built-in QML slider, so built one — `ui/Slider.qml` — and a `ui/Dropdown.qml` for the mic (input) device picker, both promoted straight to `ui/` as general-purpose atoms rather than left inline in the widget.
- [x] **6 — Updates.** `services/Updates.qml`: `Process { command: ["yay", "-Qu"] }` parsed via `StdioCollector`, refCount-gated `Timer` (15 min), manual `poll()`. Bar indicator (`UpdatesIndicator.qml`, note the `Indicator` suffix — same reason as `AudioIndicator`, to avoid the type name colliding with the `Updates` service singleton) shows `✓`/`↑N`/`…`, `N` in yellow. Popup lists pending packages (name + old → new version) with a manual refresh control.
- [x] **7 — System monitor.** `services/Sysmonitor.qml`: one `Process` (`sh -c "cat /proc/stat | head -1; ...; grep MemTotal/MemAvailable /proc/meminfo; ...; df --output=pcent /"`) per poll, refCount-gated 2s `Timer`. CPU usage is a delta between consecutive `/proc/stat` samples (cumulative counters, not an instant reading), memory from `MemAvailable`/`MemTotal`, disk from `df` on `/`. Bar indicator (`SysmonitorIndicator.qml`) shows compact `C 12% M 45% D 68%`; popup (`SysmonitorPopup.qml`) shows one label + `ui/ProgressBar.qml` per metric, red past 85%. `ui/ProgressBar.qml` is a new read-only atom (`ui/Slider.qml`'s track/fill visuals, minus the `MouseArea` — a slider is for input, this is for display, so kept as separate atoms rather than one component doing both).
- [x] **8 — Pomodoro.** `services/Pomodoro.qml`: in-memory state machine (`phase`: `work`/`shortBreak`/`longBreak`, `remainingSeconds`, `running`, `completedWorkSessions`), classic durations (25/5/15 min, long break every 4th work session), a plain 1s `Timer` gated only by `running` — not refCount, unlike the polling services, since the countdown should keep going even while no widget instance happens to be rendering it (see `AGENT.md`). Bar indicator (`PomodoroIndicator.qml`) shows `mm:ss`, dimmed when paused, green during a break. Popup (`PomodoroPopup.qml`) shows the phase label, a large `mm:ss`, a `ui/ProgressBar.qml`, and play/pause, reset, skip controls.
- [ ] **9 — Polish.** Visual consistency pass, memory footprint check, remove the placeholder widget.

Steps 2-8 each add: a service (if needed), a bar component, a popup (if applicable), and a `settings.json` entry — reviewable independently of the others.
